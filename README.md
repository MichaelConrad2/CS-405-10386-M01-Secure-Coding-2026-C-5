CS 405 – Secure Coding Portfolio
Overview
This repository contains my coursework portfolio for CS 405: Secure Coding. It showcases my understanding of secure software development, risk management, Zero Trust principles, and security policies. The projects and reflections demonstrate how security practices can be incorporated throughout the software development life cycle rather than added only at the end.
Portfolio Contents
Project One: Security Policy
My security policy project focuses on establishing guidelines and expectations for developing and maintaining secure software. It emphasizes consistent secure coding standards, access controls, and approaches to identifying and reducing security risks.
Project Two: Presentation
My presentation communicates key secure coding concepts and recommendations to an audience. It highlights why security matters during development and how teams can make informed decisions about protecting applications and data.
Coding ZIP Files
These archives contain coding work completed during the course. They are included to demonstrate the application of secure coding concepts in practice. Review the contents of each archive for its specific implementation details.
Portfolio Journal Reflection
My final journal reflects on lessons learned throughout CS 405, including:
- Adopting secure coding standards early in the development process
- Evaluating risk and the costs and benefits of mitigation
- Applying Zero Trust and the principle of least privilege
- Implementing and recommending effective security policies
Key Takeaways
Secure coding is an ongoing responsibility shared by developers and organizations. Consistent standards, early risk assessment, identity verification, and clear policies help reduce vulnerabilities and strengthen the overall security of software systems. Security controls should be evaluated for both effectiveness and practical impact on development and usability.
